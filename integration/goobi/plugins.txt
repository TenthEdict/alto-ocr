# Goobi plugins this workflow uses. Read by drift_check.sh; install.sh does
# not download plugins (fetch them by hand, see below).
#
# Columns, whitespace-separated, "-" for none or not yet known:
#   status   required = drift_check.sh fails without a matching jar
#            stock    = installed by Goobi's installer, not used by the
#                       workflow; listed so the jars are not reported as
#                       unknown (information only)
#            planned  = reported for information only
#   repo     intranda GitHub repository (github.com/intranda/<repo>)
#   jar      case-insensitive glob matched against jar file names anywhere
#            under /opt/digiverso/goobi/plugins/
#   title    the plugin name a task's "Step plugin" field holds
#   config   its config file in /opt/digiverso/goobi/config/; capture a
#            changed one into config/ next to this file
#
# Versions: install the plugin release built for the Goobi version in
# GOOBI_VERSION. intranda releases plugins alongside Goobi, so a plugin from
# another release line can fail to load with no error that names the cause.
#
# Fetch each release's -base.jar into plugins/step/ (or plugins/import/ for
# import plugins) and its -gui.jar, when it has one, into plugins/GUI/, then
# restart Tomcat. A truncated download fails as "EOFException ... read:198"
# (PROVISIONING.md section 1): re-fetch, do not debug.
#
# Jar names below are globs rather than exact names because intranda's
# naming has varied between releases. The names in the comments are the ones
# installed on the old WSL host (harvested 2026-10-15, Goobi 26.06.1). The
# file-upload and imageQA configs there were byte-identical to each plugin's
# v26.06.1 install/ default, so config/ carries no copy; the delay plugin
# had no config file at all, its title being all the task needs.

# status   repo                             jar                    title                        config
# plugin-step-file-upload-base.jar, plugin-step-file-upload-gui.jar
required   goobi-plugin-step-file-upload    *file*upload*          intranda_step_fileUpload     plugin_intranda_step_fileUpload.xml
# plugin-step-imageqa-base.jar, plugin-step-imageqa-gui.jar
required   goobi-plugin-step-imageqa        *imageqa*              intranda_step_imageQA        plugin_intranda_step_imageQA.xml
# plugin-step-delay-base.jar
required   goobi-plugin-step-delay          *delay*                intranda_delay_30_days       -
